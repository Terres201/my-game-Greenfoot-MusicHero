MUSIC HERO

Um jogo de ritmo inspirado no popular Guitar Hero.

Como Jogar

O Objetivo do jogo é chegar ao final da música com a maior pontuação possível acertando as notas no tempo certo.

Controles:
  * Player 1: `W A S D`. Player 2: `Setas Direcionais`.

## 💻 Conceitos de Programação Orientada a Objetos (POO) Aplicados

Este projeto foi desenvolvido utilizando o ambiente Greenfoot e a linguagem Java. Durante o desenvolvimento, foram aplicados conceitos fundamentais de POO, estruturando o jogo em diferentes classes.

* Herança: Criação de sub-classes a partir das classes base `World` e `Actor`.
* Encapsulamento e Métodos: Uso de métodos públicos e privados para organizar a lógica de movimentação, pontuação e transição de cenários.

Como executar este projeto

Para rodar este jogo no seu computador, você precisará ter o Greenfoot (https://www.greenfoot.org/download) instalado.

1. Faça o download ou clone este repositório: `git clone https://github.com/Terres201/my-game-Greenfoot-MusicHero.git`
2. Abra o aplicativo Greenfoot.
3. Clique em `Scenario` > `Open...` (ou Cenário > Abrir).
4. Navegue até a pasta onde você baixou o projeto e selecione o arquivo `project.greenfoot`.
5. Clique em "Compile" e depois em "Run" para jogar!
